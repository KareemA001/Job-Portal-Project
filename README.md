# Job Portal Backend

A backend REST API for a Job Portal application built while learning Spring Framework and Spring Boot.

This repository documents my learning journey as I build the application step by step, implementing new concepts, best practices, and backend features.

## Learning Goals

This project is being built to gain practical experience with:

- Spring Framework
- Spring Boot
- REST API Development
- Spring Data JPA
- Hibernate
- Validation
- Exception Handling
- Security
- Database Design
- Docker
- Production Best Practices
